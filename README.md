#Exercícios de Desenvolvimento Orientado a Objeto
Bem-vindo ao repositório dos exercícios da disciplina Desenvolvimento Orientado a Objeto! Aqui você encontrará implementações relacionadas aos padrões de projeto estudados durante o curso.

##📚 Sobre a disciplina
Na disciplina de Desenvolvimento Orientado a Objeto, exploramos os princípios fundamentais da programação orientada a objetos e mergulhamos no estudo dos padrões de projeto. Esses padrões são soluções reutilizáveis e eficazes para problemas comuns encontrados em diversas aplicações de software.

##🚀 Conteúdo do repositório
Este repositório inclui:

Implementações práticas dos padrões de projeto estudados.

Exercícios relacionados à aplicação de conceitos de orientação a objetos.

Documentação explicando cada padrão implementado.

Os padrões de projeto explorados incluem, mas não se limitam a:

Singleton

Factory Method

Observer

Strategy

Decorator
